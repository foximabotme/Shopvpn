## 📖 معرفی

**Shopvpn** یک بات تلگرام حرفه‌ای برای فروش کانفیگ‌های V2Ray است که به‌صورت کامل با Python و aiogram 3 نوشته شده. این پروژه برای استفاده‌ی واقعی و تجاری طراحی شده: چند روش پرداخت خودکار (کارت‌به‌کارت با تشخیص پیامک بانک، درگاه‌های آنلاین متعدد، کریپتو، موتور درگاه سفارشی بدون کد)، تحویل خودکار روی پنل‌های VPN محبوب، سیستم نمایندگی چندسطحی، یک دستیار پشتیبانی هوش مصنوعی، و سه لایه‌ی مدیریت مستقل — **پنل داخل بات**، **پنل وب (داخل Mini App و مستقل)** و **اپ بومی اندروید** — همه با یک تجربه‌ی کاربری کاملاً فارسی و راست‌چین.

## ✨ امکانات

### خلاصه‌ی سریع

- 🔑 تحویل خودکار (Auto-Provision) روی ۵ پنل VPN + بانک کانفیگ دستی
- 💳 هفت روش پرداخت مختلف، همه خودکار و بدون دخالت ادمین (به‌جز کارت‌به‌کارت دستی)
- 🧠 دستیار پشتیبانی هوش مصنوعی با سه ارائه‌دهنده‌ی قابل انتخاب
- 🔄 تمدید آزاد سرویس (هر مقدار حجم/روز دلخواه) روی هر پنل و با هر روش پرداخت
- 🏢 نمایندگی مستقل + حالت «نمایندگی متصل» داخل خود بات اصلی
- 🖥️ سه لایه‌ی مدیریت مستقل: پنل داخل بات، پنل وب (۵ تم قابل‌انتخاب)، اپ بومی اندروید
- 📲 اپ اندروید با اعلان Push واقعی (FCM) و به‌روزرسانی خودکار بدون نیاز به آپدیت اپ
- 🌍 نقشه‌ی جهانی سرورها با تست آنلاین/آفلاین لحظه‌ای
- 🌐 پشتیبانی از هر دو حالت **Polling** و **Webhook** برای دریافت آپدیت تلگرام

جزئیات کامل هر بخش را از زیر باز کن 👇

<details>
<summary><strong>🤖 بات اصلی (کلیک کن برای باز شدن)</strong></summary>

- 🔑 بانک کانفیگ اختصاصی و یکتا برای هر کاربر، به‌همراه **تحویل خودکار (Auto-Provision)** از طریق اتصال مستقیم به پنل‌های **PasarGuard**، **Marzban**، **Marzneshin**، **Hiddify** و **3X-UI** (ساخت کاربر و اعتبار حجمی به‌صورت آنی روی خود پنل، بدون نیاز به انبار کانفیگ دستی — به‌ویژه برای بات‌های نمایندگی)
- 🔗 **اتصال مستقیم محصولات عادی به یک پنل مشخص (بدون نمایندگی)** — ادمین موقع ساخت محصول می‌تواند آن را به یک پنل VPN وصل کند؛ با هر خرید یک کاربر واقعی همان لحظه روی همان پنل ساخته و تحویل داده می‌شود
- 🔄 **تمدید آزاد سرویس (Free-form Renewal)** — کاربر از داخل «حساب من» هر سرویس فعالش را با هر مقدار دلخواه (گیگابایت/روز، با نرخ واحد قابل‌تنظیم توسط ادمین) تمدید می‌کند؛ روی هر ۵ پنل پشتیبانی‌شده و با هر روش پرداخت کار می‌کند
- 👤 **حساب کاربری یکپارچه («حساب من»)** — همه‌ی سرویس‌های فعال کاربر (خریداری‌شده، هدیه، تست) در یک هاب با صفحه‌ی جزئیات مستقل برای هرکدام (مصرف، انقضا، تمدید، QR) قابل مشاهده است
- 🧪 **کانفیگ تست چندپلنی** — به‌جای یک تنظیم سراسری، هر پلن تست پنل/حجم/مدت/پیشوند نام مخصوص خودش را دارد (چند پلن تست هم‌زمان، هرکدام قابل‌تنظیم جدا)
- 🔢 **خرید چندتایی** — انتخاب تعداد با دکمه‌ی +/- در لحظه‌ی خرید، محاسبه‌ی خودکار جمع کل و تحویل هم‌زمان چند کانفیگ از انبار
- 💱 **نرخ خودکار دلار/تتر به تومان** — دریافت زنده از چند منبع پشتیبان (با کش کوتاه‌مدت و نرخ دستی پشتیبان در صورت قطعی همه‌ی منابع) برای قیمت‌گذاری لحظه‌ای محصولات کریپتویی
- 💰 سیستم کیف پول داخلی با درخواست شارژ، ارسال رسید و تایید ادمین
- 🗂️ مدیریت کامل دسته‌بندی و محصولات (فعال/غیرفعال، قیمت، موجودی)
- 🚫 مسدودسازی کاربر توسط ادمین (بدون تاثیر روی دسترسی خود ادمین‌ها)
- 📡 عضویت اجباری در کانال قبل از استفاده از بات (با حالت fail-open برای جلوگیری از قفل‌شدن کامل بات در صورت تنظیم اشتباه)
- 📊 اطلاعات زنده‌ی اشتراک (حجم مصرفی/باقی‌مانده و تاریخ انقضا) مستقیماً از روی لینک ساب کاربر، مستقل از نوع پنل
- ⏰ دو سیستم یادآوری خودکار و مستقل از هم: **یادآوری نزدیک‌شدن انقضا** و **یادآوری اتمام حجم**، هرکدام همراه با کد تخفیف اختصاصی و محدود به زمان
- ⚠️ هشدار خودکار اتمام موجودی محصول به همه‌ی ادمین‌ها با آستانه‌ی قابل‌تنظیم
- 📱 تحویل کانفیگ به‌صورت متن + QR Code
- 🎫 **سیستم تیکت پشتیبانی** داخل بات (ایجاد تیکت، claim، پاسخ، بستن) به‌همراه یک کانال جدا برای پیام مستقیم/چت زنده با پشتیبانی
- 🎨 دکمه‌های رنگی شیشه‌ای طبق Bot API 9.4 برای تمام دکمه‌های منوی اصلی و پنل مدیریت
- 🧩 **چیدمان و شخصی‌سازی کامل منوی اصلی** — تغییر ترتیب، نمایش/عدم‌نمایش، متن و رنگ هر دکمه از داخل پنل مدیریت
- 🏷️ برندسازی فروشگاه (نام فروشگاه، متن بنر Mini App) از داخل پنل مدیریت
- 🏢 پشتیبانی از بات‌های نمایندگی مستقل (Reseller Bots) با دیتابیس جدا برای هر نماینده و اجرای هم‌زمان چند بات با یک Dispatcher مشترک
- 🌐 **حالت اجرا: Polling یا Webhook** — قابل انتخاب با یک متغیر محیطی؛ در حالت Webhook یک سرور aiohttp مستقل درخواست‌های تلگرام را با اعتبارسنجی Secret Token دریافت می‌کند
- 💾 **ذخیره‌ی پایدار وضعیت مکالمات (FSM Storage روی SQLite)** — وضعیت مکالمات نیمه‌کاره با ری‌استارت/آپدیت/کرش بات از بین نمی‌رود؛ برای هر بات (اصلی/نمایندگی) مستقل
- ⏳ **پیام‌های خودحذف‌شونده (Temp Messages)** — ادمین می‌تواند به هر کاربر پیامی بفرستد که بعد از مدت مشخص خودکار حذف شود؛ همین مکانیزم برای حذف خودکار پیام حاوی شماره کارت هم استفاده می‌شود
- 📣 **ابزارهای مستقل ارسال پست تبلیغاتی به کانال** (`channel_post_tool.py`, `channel_add_button_tool.py`) — ارسال پست از خط فرمان یا افزودن دکمه‌ی دیپ‌لینک زیر یک پست از قبل منتشرشده

- 🎡 چرخ شانس با درصد احتمال برد، لیست جوایز، زمان انقضای کد جایزه و Cooldown قابل‌تنظیم بین دو چرخش هر کاربر

## 🧠 دستیار پشتیبانی هوش مصنوعی

یک لایه‌ی هوشمند که قبل از رسیدن پیام کاربر به ادمین انسانی، سوالات تکراری و قابل‌پاسخ‌گویی خودکار را جواب می‌دهد:

- 🔌 **سه ارائه‌دهنده‌ی قابل‌انتخاب** — Gemini، Groq یا OpenRouter، با کلید API و مدل قابل‌تنظیم از پنل ادمین (بدون نیاز به `.env` یا ری‌استارت سرور)
- 📚 پاسخ به سوالات متداول (نحوه‌ی اتصال، تفاوت پلن‌ها، سیاست بازگشت وجه و ...) که متنشان را خودِ ادمین می‌نویسد
- 🔎 پاسخ به سوالات مربوط به وضعیت واقعیِ خودِ کاربر (سرویس، انقضا، کیف پول، سفارش‌ها) با **function calling** مستقیم از دیتابیس — نه حدس زدن
- 🛒 نمایش کارت خرید واقعی (قیمت زنده، کیف پول، دکمه‌های پرداخت) از داخل مکالمه، بدون این‌که خودش چیزی تغییر دهد
- 🔒 **قانون سخت‌گیرانه:** این ماژول هیچ عملیات نوشتنی/مالی مستقیم (رفاند، تمدید، تغییر دیتابیس، تخفیف، کسر از کیف پول) انجام نمی‌دهد؛ تسویه‌ی نهایی همیشه با تایید خودِ کاربر روی دکمه‌های واقعی انجام می‌شود
- 🙋 ارجاع خودکار به پشتیبانی انسانی (`escalate_to_human`) هر وقت موضوع مالی/شکایت بود یا کاربر صراحتاً خواست
- ⚡ اگر هیچ کلید API تنظیم نشده باشد، بلافاصله و بدون تلاش برای اتصال، مکالمه به پشتیبان انسانی ارجاع داده می‌شود تا کاربر معطل نماند

## 💳 درگاه‌های پرداخت پشتیبانی‌شده

| روش پرداخت | نوع تایید | توضیح |
|---|---|---|
| 💳 کارت‌به‌کارت دستی | تایید دستی ادمین | همراه با عکس رسید |
| 📲 کارت‌به‌کارت با تشخیص پیامک بانک | خودکار، بدون درگاه | مبلغ **یکتا** برای هر فاکتور (رقم آخر تصادفی)؛ اپ اندروید مستقل **BankSmsForwarder** پیامک بانک را تشخیص و به وب‌هوک بات می‌فرستد؛ چند شماره کارت چرخشی (Round-robin)، مهلت قابل‌تنظیم (پیش‌فرض ۱۵ دقیقه) |
| 🏧 آبان گیت وی (Aban Gateway) | خودکار | فاکتور خودکار، استعلام مستقیم از API، هر بات (اصلی/نمایندگی) API Key اختصاصی خودش را تنظیم می‌کند |
| 💎 Plisio | خودکار | پرداخت کریپتو، کال‌بک امن با اعتبارسنجی امضا |
| 🔵 بلوپال (Blupal) | خودکار | کارت‌به‌کارت خودکار جایگزین؛ ساخت فاکتور و استعلام وضعیت مستقیم از API |
| ⭐ NoaPay (استارز تلگرام) | خودکار | پرداخت با استارز تلگرام؛ نرخ تبدیل واقعی از خود سرویس خوانده می‌شود |
| 🧩 موتور درگاه پرداخت سفارشی/پویا (Generic Gateway) | خودکار، بدون کد | ادمین بدون نوشتن حتی یک خط کد، هر درگاهی با HTTP API را از پنل تعریف می‌کند: آدرس API، هدر/بدنه با پلیس‌هولدر (`{amount}`, `{callback_url}`, `{api_key}`)، مسیر خواندن پاسخ (شبیه JSONPath)، و وب‌هوک با چند حالت احراز هویت (`header_secret`, `query_secret`, `hmac_sha256`) |

همه‌ی درگاه‌های خودکار مستقل از هم عمل می‌کنند و می‌توان چند تا را هم‌زمان فعال نگه داشت.

## 📲 Mini App

<details>
<summary><strong>جزئیات (کلیک کن برای باز شدن)</strong></summary>

پوشه‌ی `miniapp/` شامل یک اپلیکیشن کامل تلگرام (Telegram Mini App) با دو بخش مجزا است: **فروشگاه کاربر** و **پنل مدیریت وب کامل**.

### 🛍️ بخش کاربر
- ⚡ بک‌اند FastAPI با احراز هویت امن (HMAC-SHA256 روی initData) — آیدی کاربر همیشه سمت سرور استخراج می‌شود
- 🎨 طراحی مدرن و روشن (Light Design System) با انیمیشن و فونت Vazirmatn
- 🛒 فروشگاه، سبد خرید چندتایی، کیف پول، چرخ شانس، زیرمجموعه‌گیری و کانفیگ تست در قالب تب‌های اختصاصی
- 🔔 بنر هشدار نزدیک‌شدن انقضا/اتمام حجم در صفحه‌ی اصلی
- 📲 **افزودن خودکار اشتراک به اپ‌های VPN** — انتخاب پلتفرم (iOS/اندروید) و یکی از اپ‌های محبوب، با دکمه‌ی «⬇️ دانلود» و «📲 افزودن» (Deep Link اختصاصی هر اپ)
- 🎫 سیستم تیکت و چت پشتیبانی زنده داخل اپلیکیشن

### 🛠️ پنل مدیریت وب (داخل Mini App)

## 🖥️ پنل مدیریت وب مستقل (`admin_panel`)

<details>
<summary><strong>جزئیات (کلیک کن برای باز شدن)</strong></summary>

علاوه بر پنل مدیریتِ داخل بات و پنل مدیریتِ داخل Mini App، پروژه یک **پنل مدیریت وب کاملاً مستقل و جدا از تلگرام** هم دارد (پوشه‌ی `admin_panel/`) که می‌تواند حتی بدون باز بودن بات هم روی دامنه‌ی اختصاصی خودش بالا بماند:

- 🔐 لاگین با **یوزرنیم/پسورد** (نه از طریق تلگرام) و سیستم نشست (session) امضاشده‌ی مستقل
- 👥 **مدیریت کاربران پنل وب** با نقش و سطح دسترسی جدا از نقش‌های ادمین بات
- 📊 داشبورد کامل آمار فروش، سفارش‌ها، شارژ کیف پول و وضعیت سیستم
- 🎨 **۵ تم بصری کامل و قابل‌انتخاب** — Glass/Aurora، Cyberpunk، Bento، Neo-brutalist و Street Ops — هرکدام روی تمام صفحات پنل پیاده‌سازی شده
- 📱 **نصب به‌صورت PWA** — قابل نصب روی صفحه‌ی اصلی موبایل (اندروید/iOS) با آیکون و مانیفست اختصاصی، حتی برای هر نماینده با `start_url` جدا؛ Service Worker برای پایداری بیشتر
- 🌍 **نقشه‌ی جهانی سرورها** — اسکن خودکار لینک ساب مادر، استخراج و geolocate کردن IP سرورهای پشت هر کانفیگ (vmess/vless/trojan/ss/hysteria2/tuic)، تست سلامت واقعی در سطح پروتکل (شامل ترنسپورت `httpupgrade`) برای تشخیص دقیق‌تر آنلاین/آفلاین، با چند منبع CDN پشتیبان و کش محلی برای نمایش سریع‌تر نقشه
- 💱 نمایش و بروزرسانی دستی/خودکار نرخ ارز مورد استفاده برای قیمت‌گذاری
- ✅ تایید/رد سفارش‌ها، شارژ کیف پول و رسیدهای پرداخت مستقیماً از پنل وب (بدون نیاز به تلگرام)
- 🏢 مدیریت کامل نمایندگان به‌همراه **آنالیز کوهورت (Cohort Analytics)** نمایندگان
- 🎫 مدیریت تیکت‌ها و مکالمات پشتیبانی
- 📢 ارسال پیام همگانی (Broadcast)
- 🗄️ دریافت بکاپ فوری و بازیابی دیتابیس
- 🔔 **اعلان Push در مرورگر (Web Push / VAPID)** — اطلاع‌رسانی سفارش/تیکت/شارژ جدید حتی وقتی تب پنل بسته باشد، با فاصله‌ی زمانی بررسی قابل‌تنظیم از خود پنل
- 📱 **مدیریت اپ اندروید** — ساخت/کپی/لغو توکن دسترسی (PAT) برای اتصال اپ بومی اندروید، مستقیم از تب «اپ موبایل» داخل تنظیمات (جزئیات کامل در بخش [اپ اندروید مدیریت](#android-app))
- 📝 لاگ کامل فعالیت ادمین‌های پنل وب

### راه‌اندازی

**خودکار (پیشنهادی):** گزینه‌ی ۱۳ در `manage.sh` — دامنه، SSL و سرویس سیستم‌دی را خودش می‌سازد.

**دستی:**
```bash
# ساخت اولین حساب owner پنل وب (یوزرنیم/پسورد)
python -m admin_panel.create_admin <username> <password>

# اجرای پنل (پشت یک ریورس‌پروکسی Nginx با SSL قرار بده)
uvicorn admin_panel.server:app --host 127.0.0.1 --port 8002
```

برای فعال‌سازی اعلان‌های Push مرورگر، یک‌بار کلید VAPID بساز (یا از گزینه‌ی ۱۶ منوی `manage.sh` استفاده کن) و خروجی را داخل `.env` قرار بده:
```bash
python -m admin_panel.generate_vapid_keys
```

## 📱 اپ اندروید مدیریت

<details>
<summary><strong>جزئیات (کلیک کن برای باز شدن)</strong></summary>

پروژه یک **API اختصاصی برای اپ بومی اندروید مدیریت** هم دارد که همین پنل وب مستقل ارائه می‌کند (endpointهای `/api/app/*` در `admin_panel/server.py` + `admin_panel/mobile_auth.py` + `fcm_client.py`). خودِ اپ اندروید در ریپوی جداگانه‌ای توسعه داده می‌شود؛ این بخش از بک‌اند فقط زیرساخت لازم برای آن را فراهم می‌کند:

- 🔑 **احراز هویت با توکن دسترسی طولانی‌مدت (PAT)** — نه یوزرنیم/پسورد ذخیره‌شده روی گوشی؛ توکن از تب «📱 اپ موبایل» داخل تنظیمات پنل وب ساخته، کپی و در هر لحظه لغو می‌شود
- 🧩 **Server-Driven UI (SDUI)** — ساختار صفحات، تب‌ها، فیلدها و فرم‌های اپ از یک endpoint (`/api/app/config`) خوانده می‌شود؛ یعنی با اضافه‌شدن قابلیت جدید به پنل وب، اپ اندروید **بدون نیاز به آپدیت یا ری‌بیلد** خودش را با آن هماهنگ می‌کند
- 🔔 **اعلان Push واقعی با Firebase Cloud Messaging (FCM)** — نه صرفاً polling؛ تنظیم کاملاً از پنل وب و per-tenant (هر بات پروژه‌ی فایربیس خودش را جدا وارد می‌کند، بدون نیاز به فایل روی سرور یا ری‌استارت سرویس)
- 📋 مدیریت کامل سفارش‌ها (با رسید)، تیکت‌ها، کاربران (جست‌وجو و صفحه‌بندی کامل)، محصولات، تخفیف‌ها، پنل‌های VPN و ادمین‌های وب — شامل فرم‌های ساخت/ویرایش، نه فقط مشاهده
- 🌍 نقشه‌ی جهانی سرورها به‌صورت WebView (تنها بخشی که به‌جای SDUI مستقیم از پنل وب Embed می‌شود)
- 🎨 طراحی به سبک اپ‌های بانکی با پشتیبانی کامل از حالت روشن/تاریک (قابل تغییر از تنظیمات)
- 🔕 امکان روشن/خاموش کردن اعلان‌ها به‌تفکیک هر بخش (سفارش‌ها، تیکت‌ها، کاربران و ...)

</details>

<a id="vpn-panels"></a>

## 🔌 پنل‌های VPN پشتیبانی‌شده

<details>
<summary><strong>جدول کامل پنل‌ها (کلیک کن برای باز شدن)</strong></summary>

اتصال و **تحویل خودکار (Auto-Provision)** کاربر روی پنل، از طریق یک لایه‌ی provider مستقل (`panel_providers/`) پیاده‌سازی شده:

| نوع پنل | وضعیت | نکته |
|---|---|---|
| PasarGuard | ✅ پشتیبانی کامل | احراز هویت با Bearer token؛ گروه/اینباند کاربر جدید از روی یک کاربر نمونه‌ی از قبل موجود روی پنل کپی می‌شود |
| Marzban | ✅ پشتیبانی کامل | همان روش احراز هویت PasarGuard (لاگین با یوزر/پس روی `/api/admin/token`)؛ تفاوت فقط در نام‌گذاری فیلدهای proxies/inbounds |
| Marzneshin | ✅ پشتیبانی کامل | دسترسی کاربر از طریق «سرویس» (Service) به‌جای proxies/inbounds خام؛ endpoint احراز هویت جمع بسته (`/api/admins/token`) |
| Hiddify | ✅ پشتیبانی کامل | احراز هویت با API Key ثابت (نه لاگین یوزر/پس)؛ هویت کاربر روی پنل یک UUID است |
| 3X-UI | ✅ پشتیبانی کامل | احراز هویت با Bearer API Token، سازگار با نسخه‌های جدید که لاگین برنامه‌نویسی را می‌بندند؛ هر کاربر به یک inbound مشخص روی سرور اضافه می‌شود |
| پنل‌های دیگر | ➕ قابل افزودن | با پیاده‌سازی یک provider جدید طبق اینترفیس `panel_providers/base.py` و رجیستر آن در `panel_providers/__init__.py` |

> 💡 دریافت **اطلاعات زنده‌ی اشتراک** (حجم/انقضا از روی لینک ساب کاربر — `sub_info.py`) کاملاً مستقل از این لایه است و با هر نوع پنلی کار می‌کند، چون مستقیم خروجی ساب را می‌خواند نه API پنل را.

</details>

<a id="auto-install"></a>

## 🚀 نصب خودکار (یک‌خطی، پیشنهادی)

برای نصب کامل بات روی یک سرور تازه (Ubuntu/Debian)، فقط این دستور را در ترمینال سرور اجرا کن:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mehdirafatpanah/Shopvpn/main/manage.sh)
```

<details>
<summary>این اسکریپت دقیقاً چه کار می‌کند؟</summary>

1. ✅ پیش‌نیازهای سیستمی (`git`, `python3`, `pip`, `venv`) را نصب می‌کند
2. ✅ پروژه را از گیت‌هاب کلون می‌کند (یا در صورت وجود، آپدیت می‌کند)
3. ✅ محیط مجازی پایتون را می‌سازد و پکیج‌ها را نصب می‌کند
4. ✅ توکن بات و آیدی عددی ادمین را از تو می‌پرسد و فایل `.env` را می‌سازد
5. ✅ یک سرویس `systemd` می‌سازد تا بات همیشه در حال اجرا بماند و بعد از ری‌استارت سرور هم خودکار بالا بیاید

بعد از پایان نصب می‌توانی با دستورهای زیر وضعیت بات را مدیریت کنی:

```bash
sudo systemctl status v2raybot     # وضعیت بات
sudo journalctl -u v2raybot -f     # مشاهده لاگ زنده
sudo systemctl restart v2raybot    # ری‌استارت
sudo systemctl stop v2raybot       # توقف
```

برای آپدیت بات در آینده، کافیست همان دستور نصب یک‌خطی بالا را دوباره اجرا کنی (idempotent است و اطلاعات `.env` را دست‌نخورده نگه می‌دارد)، یا از [پنل مدیریت متنی (`manage.sh`)](#manage-sh) استفاده کنی.

</details>

<a id="manual-install"></a>

## 🛠 نصب دستی

<details>
<summary><strong>مراحل کامل نصب دستی (کلیک کن برای باز شدن)</strong></summary>

**۱. کلون کردن پروژه**
```bash
git clone https://github.com/mehdirafatpanah/Shopvpn.git
cd Shopvpn
```

**۲. ساخت محیط مجازی و نصب پکیج‌ها**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

**۳. تنظیم فایل `.env`**
```bash
cp .env.example .env
nano .env
```

مقادیر زیر را در فایل `.env` قرار بده:
```env
BOT_TOKEN=توکن_واقعی_بات
OWNER_ID=آیدی_عددی_تو
```

> 🔒 فایل `.env` هرگز نباید وارد گیت‌هاب شود (در `.gitignore` قرار دارد). فقط `.env.example` بدون مقدار واقعی در ریپازیتوری نگه‌داری می‌شود.

**۴. اجرا**
```bash
python main.py
```

اگر همه‌چیز درست باشد، بات بلافاصله روشن می‌شود و آماده‌ی دریافت پیام است. دیتابیس به‌صورت خودکار در همان پوشه ساخته می‌شود (`bot_database.db`)؛ نیازی به نصب هیچ دیتابیس جداگانه‌ای نیست.

**۵. اجرای دائمی (بدون بستن ترمینال)**
```bash
# روش ساده با screen
screen -S v2raybot
python main.py
# سپس Ctrl+A و D برای خروج بدون بستن بات

# یا با nohup
nohup python main.py > bot.log 2>&1 &
```

بهترین روش برای پروداکشن، ساخت یک سرویس `systemd` است (که [نصب خودکار](#auto-install) این کار را خودش انجام می‌دهد).

> 💡 بعد از نصب دستی هم می‌توانی مدیریت روزمره‌ی بات را با [پنل مدیریت متنی (`manage.sh`)](#manage-sh) انجام دهی.

</details>

## ⚙️ متغیرهای محیطی (.env)

`BOT_TOKEN` و `OWNER_ID` تنها متغیرهای **اجباری** هستند؛ بدون آن‌ها بات اصلاً بالا نمی‌آید. بقیه‌ی متغیرها اختیاری‌اند و فقط قابلیت مربوطه را فعال می‌کنند — اگر خالی بمانند، همان بخش به‌آرامی غیرفعال می‌ماند و بقیه‌ی پروژه بدون مشکل کار می‌کند.

<details>
<summary><strong>جدول کامل متغیرها (کلیک کن برای باز شدن)</strong></summary>

| متغیر | اجباری؟ | توضیح |
|---|:---:|---|
| `BOT_TOKEN` | ✅ | توکن بات اصلی، از [@BotFather](https://t.me/BotFather) |
| `OWNER_ID` | ✅ | آیدی عددی تلگرام مالک پروژه |
| `BOT_MODE` | ➖ | `polling` (پیش‌فرض) یا `webhook`؛ این دو هم‌زمان روی یک توکن کار نمی‌کنند |
| `WEBHOOK_BASE_URL` | ➖ | آدرس عمومی HTTPS که تلگرام آپدیت‌ها را به آن پوش می‌کند؛ فقط در حالت `webhook` لازم است |
| `WEBHOOK_SECRET` | ➖ | توکن مخفی تلگرام برای اطمینان از اصالت درخواست وب‌هوک |
| `WEBHOOK_LISTEN_HOST` / `WEBHOOK_LISTEN_PORT` | ➖ | آدرس/پورت داخلی سرور aiohttp وب‌هوک (پیش‌فرض `127.0.0.1:8010`) |
| `MINIAPP_URL` | ➖ | آدرس HTTPS مینی‌اپ؛ خالی یعنی دکمه‌ی مینی‌اپ در بات نمایش داده نمی‌شود |
| `API_BASE_URL` | ➖ | آدرس پایه‌ی API مینی‌اپ (برای کال‌بک پرداخت کریپتو)؛ اگر خالی باشد خودکار از روی `MINIAPP_URL` استخراج می‌شود |
| `PLISIO_API_KEY` | ➖ | کلید API [Plisio](https://plisio.net) به‌عنوان فال‌بک سراسری (هر بات کلید اختصاصی خودش را هم از پنل تنظیم می‌کند) |
| `ABANGATEWAY_API_KEY` | ➖ | کلید API [آبان گیت وی](https://abangateway.ir) به‌عنوان فال‌بک سراسری |
| `BLUPAL_API_KEY` | ➖ | کلید API درگاه بلوپال به‌عنوان فال‌بک سراسری |
| `NOAPAY_API_KEY` / `NOAPAY_WEBHOOK_SECRET` | ➖ | کلید API و سکرت وب‌هوک درگاه NoaPay (استارز تلگرام) |
| `GEMINI_API_KEY` / `GROQ_API_KEY` / `OPENROUTER_API_KEY` | ➖ | کلید API دستیار پشتیبانی هوش مصنوعی، بسته به ارائه‌دهنده‌ی انتخابی (قابل تنظیم از پنل هم هست) |
| `AI_SUPPORT_MODEL` | ➖ | نام مدل دستیار هوش مصنوعی (پیش‌فرض `gemini-2.5-flash-lite`) |
| `ADMIN_PANEL_SECRET` | ➖ | کلید امضای نشست (session) پنل مدیریت وب مستقل؛ اگر ست نشود مقدار تصادفی ساخته می‌شود |
| `ADMIN_PANEL_URL` | ➖ | آدرس دامنه‌ی پنل مدیریت وب مستقل (`admin_panel/`) |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | ➖ | کلیدهای اعلان Push مرورگر برای پنل وب مستقل؛ با `python -m admin_panel.generate_vapid_keys` ساخته می‌شوند |
| `VAPID_CLAIM_EMAIL` | ➖ | ایمیل تماس همراه کلید VAPID (پیش‌فرض: `admin@example.com`) |
| `FIREBASE_SERVICE_ACCOUNT_PATH` | ➖ | مسیر فایل JSON سرویس‌اکانت فایربیس برای Push اپ اندروید، به‌عنوان جایگزین سراسری (روش پیشنهادی، تنظیم per-tenant از پنل وب → تنظیمات → اپ موبایل است) |

</details>

## 🗂 ساختار پروژه

| `database.py` | کلاس `Database` — هر بات (اصلی/نمایندگی) یک نمونه‌ی مستقل دارد |

| `handlers_user.py` | هندلرهای مربوط به کاربر عادی |
| `handlers_admin.py` | هندلرهای پنل مدیریت (شامل نقش‌ها، بکاپ/بازیابی، لاگ، تیکت و...) |

| `sub_info.py` | دریافت اطلاعات زنده‌ی اشتراک (حجم/انقضا) از روی لینک ساب، مستقل از نوع پنل |
| `renewal_engine.py` | منطق مشترک اجرای واقعی «تمدید سرویس» از حساب کاربری، برای همه‌ی مسیرهای تایید پرداخت |
| `renewal_reminders.py` | یادآوری خودکار تمدید سرویس و اتمام حجم |
| `stock_alerts.py` | هشدار اتمام موجودی محصول به ادمین‌ها |
| `blocked_user.py` | میان‌افزار مسدودسازی کاربر |
| `force_join.py` | عضویت اجباری در کانال/گروه |
| `fsm_storage.py` | پیاده‌سازی سبک FSM Storage پایدار روی SQLite (جایگزین MemoryStorage) |
| `temp_messages.py` | ارسال پیام خودحذف‌شونده و زمان‌بندی حذف خودکار یک پیام موجود |

| `test_config_provision.py` | ساخت کانفیگ تست از روی پلن‌های چندمدلی (`test_config_plans`)، هرکدام با پنل/حجم/مدت/پیشوند خودش |
| `ai_support.py` | دستیار پشتیبانی هوش مصنوعی (Gemini/Groq/OpenRouter) با function calling و ارجاع به پشتیبان انسانی |
| `abangateway_client.py` / `abangateway_payment.py` | کلاینت و منطق درگاه [آبان گیت وی](https://abangateway.ir) |
| `blupal_client.py` / `blupal_payment.py` | کلاینت و منطق درگاه [بلوپال](https://www.blupal.net) |
| `noapay_client.py` / `noapay_payment.py` | کلاینت و منطق درگاه NoaPay (پرداخت با استارز تلگرام) |

| `payment_engine.py` | موتور عمومی درگاه پرداخت پویا (`GenericGateway`) بر اساس یک config جیسون |

| `channel_post_tool.py` / `channel_add_button_tool.py` | ابزارهای خط‌فرمان ارسال/ویرایش پست تبلیغاتی در کانال |
| `backup.py` | بکاپ‌گیری خودکار/دستی و بازیابی دیتابیس |
| `jalali.py` | تبدیل و قالب‌بندی تاریخ شمسی (جلالی) |
| `crypto_payment.py` / `plisio_client.py` | منطق مشترک و کلاینت درگاه پرداخت کریپتو [Plisio](https://plisio.net) |

| `world_map.py` | کش و سرو کردن دارایی‌های نقشه‌ی جهانی (d3-geo/topojson) برای داشبورد |
| `geo_scan.py` | اسکن لینک ساب مادر، geolocate سرورها و تست سلامت پروتکل‌محور برای نمایش روی نقشه |
| `reseller_auto_provision.py` | تحویل خودکار محصولات «اعتبار حجمی» با ساخت کاربر مستقیم روی پنل برای بات‌های نمایندگی |
| `fcm_client.py` | کلاینت Firebase Cloud Messaging (HTTP v1) برای Push اپ اندروید مدیریت |
| `panel_providers/` | لایه‌ی مستقل اتصال به پنل‌های VPN — [جزئیات](#vpn-panels) |
| `admin_panel/` | [پنل مدیریت وب کاملاً مستقل](#admin-panel) (`server.py` بک‌اند FastAPI + endpointهای اپ موبایل، `mobile_auth.py` صدور توکن PAT، `create_admin.py` ساخت حساب owner، `security.py` هش پسورد/نشست، `webpush.py` + `generate_vapid_keys.py` اعلان Push مرورگر، `telegram_notify.py`، `config_delivery_web.py`) |
| `miniapp/` | Mini App (بک‌اند FastAPI + فرانت‌اند + پنل مدیریت وب) |

## 🧪 تکنولوژی‌های استفاده‌شده

| بخش | تکنولوژی |
|---|---|
| زبان اصلی | Python 3.10+ |

| پرداخت آنلاین/کریپتو | آبان گیت وی، Plisio، بلوپال، NoaPay |
| اعلان Push | Web Push (VAPID) + Firebase Cloud Messaging |
| مدیریت سرور | systemd, Bash, Nginx |
| کنترل نسخه | Git / GitHub |
